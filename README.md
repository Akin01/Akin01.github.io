## ⚡ Overview

Personal engineering portfolio and technical project catalog for **Ainul Yaqin** ([@Akin01](https://github.com/Akin01)), Tech Lead and Software Engineer based in Yogyakarta, Indonesia (UTC+7).

### Key Features & Architecture

- **Interactive CLI Terminal Shell**: Fully interactive in-browser bash shell with live command execution (`help`, `whoami`, `projects`, `skills`, `specs`, `contact`, `clear`).
- **3D Magic Project Deck**: 3-stack interactive card deck with physical pointer physics, drag swipe gestures, and in-card slide transitions between visual README previews and technical architecture specifications.
- **Dynamic Multi-Curve Experience Route**: Topological route line calculated with smooth cubic Bézier curves connecting career milestones, drawing and lighting stations progressively with direct scroll synchronization.
- **Technical Matrix Tree Abstract**: Monospace UNIX directory tree representation of runtime engines, protocols, applied AI, and verified certifications.
- **ASCII Canvas Art**: Dynamic character-canvas portrait rendered via custom canvas pixel shaders.
- **Momentum Smooth Scroll**: Integrated [Lenis](https://lenis.dev/) smooth scrolling synchronized 1:1 with GSAP ScrollTrigger for 60/120 FPS performance with zero scroll friction.

## 💻 Development

### Prerequisites

- Node.js `>= 22.0.0`
- pnpm `>= 10.0.0`

### Commands

```sh
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build production static bundle to ./dist
pnpm build

# Preview production build locally
pnpm preview
```
